# NOCTERRA

Fondasi web NOCTERRA menggunakan React, TypeScript, dan Vite. Antarmuka awal memakai palet hutan malam dan belum menyertakan fitur ambience, audio, atau animasi.

## Menjalankan aplikasi

```sh
npm install
npm run dev
```

## Pemeriksaan

```sh
npm run typecheck
npm run build
```

## Arah visual

Lihat [DESIGN.md](DESIGN.md) untuk palet, tipografi, komposisi, dan dial desain.
